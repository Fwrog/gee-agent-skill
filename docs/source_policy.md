# Source Policy

The canonical source policy lives at [../references/sources/source_policy.md](../references/sources/source_policy.md).

In short:

- Tier A official Earth Engine sources dominate current API and dataset facts.
- Research papers support methodology and evaluation framing only.
- Community repositories support distilled implementation patterns only.
- Source discovery creates candidates; promotion requires review.
- Public source, evidence, and graph files must not include private assets, credentials, local paths, private Drive folders, unpublished manuscript claims, or copied third-party code.
