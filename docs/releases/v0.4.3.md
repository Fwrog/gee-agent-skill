# v0.4.3 Release Notes

`gee-agent-skill` v0.4.3 closes the next public knowledge-loop milestone without importing private project context or third-party code.

## Added

- Generic HLS/MODIS NDVI `product_intercomparison` planning with three registered products, a 250 m MODIS target-grid contract, temporal matching, QA policies, and deterministic validation rules.
- A seven-case local quick benchmark using the unit/combination/theme structure from AutoGEEval++; local pass rates are explicitly not comparable with the external benchmark.
- A 200-project direct-domain-evidence GitHub queue. Its discovery snapshot stays metadata-only; a separate ledger contains 24 pinned deep reviews: 21 from the queue and 3 anchor sources, leaving 179 queue records unreviewed.
- Nine reviewed project-paper pairs: seven yielded bounded reusable patterns and two were retained as general context without promotion.
- Ten new accepted cards for runtime-wrapper equivalence, temporal segmentation, wrapper preprocessing, data-cube materialization, benchmark protocol, catalog publication, Sentinel-1 ARD, geospatial ML generation, asset ingestion, and export readback.
- A 17-case mistake-distillation lab. Important omissions must resolve to an existing rule or evidence-card identifier; general observations remain non-blocking.
- A two-layer learning architecture: versioned official knowledge remains separate from user-owned Obsidian Skills. `gee-skill learning contract` exposes the handoff contract, while `learning review-manifest` performs read-only review of a sanitized candidate without reading the source vault or promoting it.

## Fixed

- The privacy release scan now skips Git-listed paths that have already been deleted from the worktree. Existing tracked or pending files are still scanned; a focused regression prevents deleted files from crashing the release gate.

## Verification Snapshot

- 218 repository tests, the 14-check release gate, the 7-case quick benchmark, and the 22-case main benchmark pass locally.
- CLI smoke testing and both `learning` commands pass; the example review returns `candidate_review_ready` with `official_promotion: false`.
- The official repository Skill and the separately maintained user-owned mistake-distiller Skill both pass structural Skill validation.
- Wheel and source distributions build successfully; the source distribution includes the promotion schema and sanitized example manifest.
- End-to-end manifest review confirms that project aliases, raw evidence references, and note bodies are absent from the public review payload.

## Boundaries

- Papers supply evaluation or retrieval structure, not current Earth Engine facts.
- Community repositories supply paraphrased patterns only; no source code was copied.
- Omitted private or unpublished context is intentionally unknown and must not be inferred or published.
- The 200-item inventory is not represented as 200 completed reviews or 200 authoritative sources.
- Evaluation success requires a schema-matched runner and a positive executed-case count; zero-case “green” results are rejected.
- The dedicated KG-RAG retrieval regression executes 21 cases after the index and graph are rebuilt.
- A valid local-learning manifest is only review-queue admission; it is not official promotion or scientific evidence.
- The generic comparison recipe is planning and validation capability, not a generic live template or an in-situ ground-truth claim.
