# v0.4.2 Release Notes

Release date: 2026-07-30

`gee-agent-skill` v0.4.2 packages the current public harness as a concise, privacy-reviewed GitHub release.

## Highlights

- A shorter `SKILL.md` keeps the normal GEE path, safety gates, claim boundaries, and progressive-disclosure links.
- The annual endpoint-transition recipe adds fixed-grid, tile-filtering, categorical-fraction, and bounded-export safeguards. Its public evidence level remains render-and-validate only.
- The private-raster handoff keeps credentials and study-specific identifiers outside the repository while allowing agent-owned validation to resume after a minimal authority checkpoint.
- The bilingual README now presents one compact project overview and links detailed scientific validation to dedicated documentation.
- Package metadata, CLI version, citation metadata, and release notes are aligned at `0.4.2`.

## Public Boundary

The release contains reusable code, generic examples, public evidence cards, and reviewed validation artifacts. It does not contain real private project or asset IDs, bucket or object names, task IDs, private rasters, manuscript drafts, or unpublished results.

## Verification

Run from the repository root:

```bash
python -m pytest
python scripts/ingest_docs.py
python scripts/release_gate_kg_rag.py --json
python -m build --sdist --wheel
```

Live Earth Engine execution remains opt-in and requires the user's own project, authentication, passing preflight, and `--confirm-live`.
